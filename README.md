# Machine Learning Specialization

Study guides and reports from Andrew Ng's Machine Learning Specialization (DeepLearning.AI / Stanford Online on Coursera), written while working through the three courses.

## Contents

### 1. Supervised Machine Learning: Regression and Classification
- Linear regression and gradient descent
- Multiple regression, feature scaling and vectorization with NumPy
- Logistic regression and classification

### 2. Advanced Learning Algorithms
- Neural networks and forward propagation
- Activation functions (ReLU, Softmax) and multiclass classification
- Model evaluation, bias/variance, cross-validation, precision/recall/F1
- Decision trees and ensemble methods

### 3. Unsupervised Learning, Recommenders, Reinforcement Learning
- K-means clustering and anomaly detection
- PCA
- Collaborative and content-based filtering
- Reinforcement learning, the Bellman equation and Deep Q-learning

## Structure

Each course has a folder, with one subfolder per week containing PDF study guides and reports.
